    Discord webhook

    Server Settings → Integrations → Webhooks → New Webhook → Copy URL.

    eBay account deletion endpoint

    eBay requires this before production API keys work. Paste the public URL of /ebay/notifications, generate a token, save, then register both on developer.ebay.com/my/keys. Deletion notices are forwarded to Discord.

    Card price index

    TCGplayer market prices come from the daily tcgcsv.com dumps. Build the index once so card search works; it takes a few minutes.
